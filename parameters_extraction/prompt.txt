Strict Extraction Rules 
Rule 1 — Exact Values Preferred, Intelligent Inference Allowed
Primary rule: record values that are explicitly stated in the paper.
However, if a value is NOT explicitly stated but can be reasonably inferred from the text, you MAY calculate/derive it using obvious logic. Examples:
- Daily load demand given but no annual: multiply by 365 to get annual
- LPSP stated as "<1%": record as "<1%" or "1%" with a note
- COE reported but not LCOE: record COE in the LCOE field with a note explaining
- Component count and individual capacity given: multiply for total capacity
When you infer a value, ALWAYS explain the calculation/source in the NOTES column.
Never hallucinate — if no basis exists for inference, leave blank or null.
Rule 2 — Preserve Units Exactly 
Every numerical value must include the unit exactly as reported in the paper. 
Examples: 

327 W 
0.327 kW 
33.3 kWh/kg 
5 % 
2.639 kg CO₂/L 
0.82 USD/L 
Never remove the units. 
Rule 3 — Unit Mismatch 
If the paper reports the correct parameter but in a different unit than the reference list: 

copy the value exactly as written, 
include the reported unit, 
do NOT convert it, 
add a note in the NOTES column explaining the unit mismatch. 
Example: 
NOTES: 

rated_PV reported as 327 W instead of kW. 
Rule 4 — Similar Parameters 
If the paper reports a similar but not identical parameter, DO NOT place it into the parameter cell. 
Instead, leave the intended cell blank and document the finding in NOTES. 
Examples include: 

restoration cost instead of replacement cost 
salvage value 
maintenance coefficient 
degradation coefficient 
capital recovery factor 
annualized cost 
battery storage instead of hydrogen storage 
renewable fraction 
NPC instead of COE 
LOLP instead of LPSP 
The spreadsheet must only contain values corresponding exactly to the requested parameter. 
Rule 5 — Missing Values 
If a parameter cannot be found after carefully checking the paper: 

leave the cell blank (preferred) 
or write N/A 
Never invent values. 
Rule 6 — Total Annual Load Demand
If the annual value is explicitly reported, use it directly.
If only daily load is given, multiply by 365 to get annual and note the calculation in NOTES.
If hourly profile data is given, sum all hourly values to get annual and note in NOTES.
If neither is available, leave blank and mention what load data IS available in NOTES.
Rule 7 — LCOE, COE, and LPSP
Record these metrics if explicitly reported.
If a bound is given (e.g., "LPSP < 1%"), record the bound value with a note.
If COE is given but not LCOE (or vice versa), you may use the available value in both fields with a note explaining.
Never fabricate — if no value or bound exists, leave blank.
Rule 8 — Tables and Figures 
Values may appear in: 

tables 
figure annotations 
captions 
appendices 
supplementary information 
Extract these if they are explicitly labeled. 
Do not estimate values from chart axes or plotted curves. 
Rule 9 — Multiple Case Studies 
If a paper reports multiple scenarios or case studies: 

use the primary or baseline configuration if clearly identified. 
If no single baseline exists, note the ambiguity in the NOTES column and, if appropriate, create separate rows for each clearly distinguished case (e.g., "Paper X – Case 1", "Paper X – Case 2"), maintaining the same column structure. 
Rule 10 — Notes Column 
The NOTES column should capture information such as: 

parameter missing 
unit mismatch 
similar but different parameter 
ambiguous terminology 
multiple reported values 
assumptions explicitly mentioned by the authors 
values reported only graphically 
reported ranges instead of single values 
alternative definitions 
The NOTES column should not contain speculative explanations.
